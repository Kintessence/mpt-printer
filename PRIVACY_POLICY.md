# Política de Privacidade - Air Printer

O aplicativo **Air Printer** foi desenvolvido para oferecer integração ágil entre sistemas web/recibos e impressoras térmicas via Bluetooth.

### Coleta e Uso de Informações
- **Bluetooth:** Utilizado exclusivamente para comunicação direta com a impressora térmica pareada. Nenhum dado de dispositivo Bluetooth é transmitido para servidores de terceiros.
- **Internet:** Utilizada unicamente para baixar o conteúdo do comprovante/URL que o próprio usuário optou por compartilhar com o aplicativo.
- **Dados Pessoais:** O Air Printer não armazena, não rastreia e não compartilha dados cadastrais, financeiros ou dados presentes nos recibos processados.
